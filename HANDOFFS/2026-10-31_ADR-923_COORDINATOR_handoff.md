## Σειρά τρένων

Ένα τρένο τη φορά, ένα push, επαλήθευση, μετά το επόμενο. Στη σειρά: Φ3 διορθώσεις → Φ4 → Φ5.
Οι Φ4 και Φ5 αλλάζουν κανόνες και δείκτες, άρα το pipeline ζητά έγκριση Giorgio στο GitHub Actions.
Στο rebase: `.i18n-shell-slice.json` (`lazyAdmissionSeal`) · `rules-liveness-gate` · `check-catalog-schema-authority.js`.
Το commit του CHECK 3.64 γίνεται κενό cherry-pick.

## Πρώτη ενέργεια της νέας συνεδρίας

Ο Giorgio ενέκρινε την πρόταση «ένα τρένο με τρία κλαδιά, ένα push» (31/10) και ζήτησε να γίνει σε νέα συνεδρία. Η εντολή ισχύει όταν γράφεται στο prompt της νέας συνεδρίας· αλλιώς ρώτα.

1. Έλεγξε `npm run wt:list` και ότι τα τρία κλαδιά είναι καθαρά. Μη γράψεις σε ξένο worktree δουλειά που δεν σου ανήκει· ρώτα τη συνεδρία του.
2. Από αυτό το worktree (το `wt:land` βρίσκει μόνο του το κύριο αντίγραφο, και το εργαλείο αρνείται εντολές git με `cd` εκεί), σε background, ένα τη φορά:
   `npm run wt:land -- adr-923-phase3-close` → `npm run wt:land -- adr-923-phase4-import-b` → `npm run wt:land -- adr-923-phase5-publisher-b`.
3. Το `lazyAdmissionSeal`: το main έχει 321, η Φ4 323, η Φ5 321 → 322. Μετά το rebase μέτρα το πραγματικό σύνολο και σφράγισε με γραμμένο `why` (εγκρίθηκε από τον Giorgio). Αν η πύλη ζητά κάτι άλλο, σταμάτα και ανάφερε.
4. Αν το `wt:land` βρει σύγκρουση, το κλαδί μένει ως είχε: λύσ' την στο worktree του κλαδιού. Οι πύλες δεν παρακάμπτονται ποτέ.
5. `git push origin main` **μία** φορά, μόνο όταν μπουν και τα τρία. Το pipeline θα σταματήσει στο `firebase-production`: ο Giorgio εγκρίνει στο GitHub Actions. Αν το build θέλει ~15′, κανένα άλλο push.
6. Επιβεβαίωσε την έκδοση από το `/api/build-info`, μέσα από τον Chrome (το `curl` από εδώ γύρισε κενό).
7. Ζωντανός έλεγχος, χωρίς εισαγωγή κωδικού από πράκτορα: οι διορθώσεις παρακάτω · οθόνη `/catalog/imports` · οθόνη του εκδότη. Το κριτήριο της Φ4 θέλει PDF κεφαλαίου Aries και πληρωμένη κλήση AI: ζήτα έγκριση κόστους πριν. Το κριτήριο της Φ5 θέλει Typst.
8. Κλείσε τα ADR-923 Status · §9 ανά φάση με ό,τι αποδείχθηκε, όχι με ό,τι γράφτηκε.

Η Φ6 τρέχει στη `nestor-pagonis-26`, και η Φ7 χρειάζεται δική της νέα συνεδρία. Τρέξε `ListAgents` και δήλωσε τον νέο συντονιστή. Για τη Φ6 πες της να κάνει rebase μόνο μετά το τρένο.
