## 4. ΕΠΟΜΕΝΟ — (β) χάρτης κατάστασης πάνω στο PDF + αμφίδρομη επιλογή
Πλήρης προδιαγραφή: **προηγούμενο handoff §5**. Σύνοψη:
- Πλαίσια γύρω από **όλα** όσα αναγνωρίστηκαν: 🔵 εκκρεμεί (λεπτή συνεχής) · 🟢 αντιστοιχίστηκε/αποδεκτό (παχιά + ✓) · 🔴 πρόβλημα/χωρίς πεδίο (διακεκομμένη + !) · ⬜ επιλεγμένο (γκρι γέμισμα, όπως σήμερα). **Όχι μόνο χρώμα** (CHECK 3.41), χρώματα από **tokens**, χαρτί λευκό σε κάθε θέμα, **υπόμνημα** + διακόπτης «εμφάνιση πλαισίων».
- **Αμφίδρομη επιλογή, ΕΝΑΣ κάτοχος:** λίστα→PDF (υπάρχει, γκρι) · PDF→λίστα (κύλιση + ενεργοποίηση + εστίαση· αν το κρύβει το φίλτρο ⇒ εμφάνιση με εξήγηση) · ένα πλαίσιο → πολλά πεδία («1 από 4 · επόμενο») · πλαίσια = κουμπιά με `aria-label`, Tab-προσβάσιμα.
- **Σειρά εργασίας:** (1) έρευνα web (Rossum · Azure DI Studio · ABBYY Vantage · Hypatos · Adobe Acrobat: status overlay, multi-field box, στόχος κρυμμένος από φίλτρο) → (2) **SSoT audit (grep)**: πού ζει η γκρι επισήμανση (ζωγράφος `regions`), αν είναι κοινή με άλλες οθόνες, αν υπάρχει store επιλογής (π.χ. `useCatalogSelection`, `focused`/`onFocus` του `ProposalReview`), αν τα `regions` φτάνουν για πεδία **και** γραμμές (Β3.1: 12/12), υπάρχοντα tokens κατάστασης (ADR-771 κανάλι κατάστασης) → (3) Plan Mode (εκτίμηση 5–7 αρχεία, 1 πεδίο) → (4) ADR-923 ενότητα + changelog.
