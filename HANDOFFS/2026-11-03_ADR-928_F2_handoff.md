## Παγίδες που μετρήθηκαν στη Φ1 (μην τις ξαναπληρώσεις)
- **Το fake Firestore ΔΕΝ επιβάλλει «όλες οι αναγνώσεις πριν από κάθε εγγραφή»** (δηλωμένο όριο). Η πραγματική Firestore
  το επιβάλλει: σε συναλλαγή πολλών εγγράφων διάβασε **όλα** πρώτα (`getAll`), όπως η σπορά.
- **Harness κανόνων**: το `defineServerWrittenTenantAnchors` χτίζει το id από το όνομα της συλλογής ⇒ με διαδρομή
  υποσυλλογής σπέρνει σε λάθος θέση. Για υποσυλλογές γράψε ρητές άγκυρες (πρότυπο: `subcontract-clauses.rules.test.ts`).
- **jest + sha256**: Web Crypto δεν υπάρχει στο jsdom ⇒ `@jest-environment node` σε κάθε σουίτα που αγγίζει αποτυπώματα.
- **`jscpd:diff` με φακέλους** απαντά «0 κλώνοι» χωρίς να κοιτάξει όλα τα αρχεία — δώσε **ρητή λίστα αρχείων**.
- **Μητρώο ιστορικού**: `'subcollection'` σημαίνει `companies/{c}/<col>`· για ένθετη υποσυλλογή οντότητας το σχήμα του
  `engagement` (`collectionKey: null`) + `SUBCOLLECTIONS` + `SUBCOLLECTION_PARENTS` (backup).
- Νέες ετικέτες τύπου οντότητας ⇒ `common.json` (el+en) + `npm run generate:i18n-types` + `npm run generate:i18n-shell-slice`.
- Νέα πύλη / αλλαγή σε `docs/gates/` ⇒ `node scripts/generate-gate-index.js` (ο πίνακας του `CLAUDE.md` παράγεται).
- Ο φύλακας του worktree αρνείται εντολές με μεταβλητές/`xargs`: γράψε script στο scratchpad με ρητές διαδρομές.
