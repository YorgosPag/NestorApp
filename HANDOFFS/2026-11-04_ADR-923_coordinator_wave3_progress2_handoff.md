## Μαθήματα αυτής της συνεδρίας (ΚΡΙΣΙΜΑ)
- **Πράκτορας ΔΕΝ μπαίνει σε ξένο worktree** από αυτή τη συνεδρία: `SendMessage` σε παλιό id ⇒ «No transcript»· `EnterWorktree path` χωρίς isolation ⇒ «not inside the repository»· με `isolation: worktree` ⇒ «would not give write access». Αδέσμευτη δουλειά νεκρού πράκτορα = **χαμένη** ⇒ ξαναγίνεται σε **νέο κλαδί** από την κορυφή του παλιού (το παλιό κλαδί είναι δεσμευμένο από το κλειδωμένο worktree).
- **Ανασκοπήσεις χωρίς worktree**: πράκτορας χωρίς isolation, μόνο `git show`/`git diff main...<κλαδί>` (κοινά refs). Δουλεύει.
- **Ο φύλακας απομόνωσης μπλοκάρει και τα `!` του Giorgio** με `cmd`/`git -C`. Σβήσιμο φακέλων ⇒ Giorgio σε **ξεχωριστό PowerShell** (`git worktree remove -f -f <dir>` για κλειδωμένα· `git worktree prune`)· PowerShell multi-line ⇒ χρειάζεται επιπλέον Enter.
- **«όπως οι μεγάλοι» ΔΕΝ είναι εντολή land/push** για τον ταξινομητή· χρειάζεται ρητό «κάνε land και push».
- **Deploy**: build Docker ~22′. Νεότερο push άλλης συνεδρίας **ακυρώνει** την κυκλοφορία του δικού μας run (το νεότερο το περιέχει). Αν το νεότερο αλλάζει κανόνες Firebase, **περιμένει έγκριση Giorgio** στο GitHub — τότε και το δικό μας δεν φτάνει στην παραγωγή. Έλεγχος: `gh run view <id> --json jobs` + `/api/build-info` στον browser.
- `wt:land` = η ουρά ένταξης (rebase στο τρέχον main + reset --soft + 1 commit + πλήρες hook, ff-only). Λειτουργεί με όνομα κλαδιού χωρίς `agent/` ακόμη κι αν το worktree είναι κάτω από `.claude\worktrees`.
