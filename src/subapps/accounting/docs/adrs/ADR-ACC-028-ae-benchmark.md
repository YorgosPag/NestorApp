| Θέμα | Περιεχόμενο | Βεβαιότητα |
|---|---|---|
| Κεφάλαιο | Ελάχιστο ⚠️ (αναφέρεται 25.000 €) | ⚠️ |
| Όργανα | Γενική Συνέλευση, Διοικητικό Συμβούλιο | γενική γνώση |
| Βιβλία | Διπλογραφικά | γενική γνώση |
| Φόρος | 22% + 5% στα μερίσματα | ⚠️ |
| Προκαταβολή | 80% | ⚠️ |

## 2. Τι έχουμε (κώδικας — βλ. ACC-015/016/017)

- Μέτοχοι με `isBoardMember`, αμοιβές, μετοχές, `efkaMode` (`components/setup/ShareholderManagementSection.tsx`, `types/entity.ts:~185-218`).
- `calculateAETax` πάνω στον υπολογισμό ΕΠΕ (`services/engines/tax-engine.ts:~328-372`), μερίσματα ανά μέτοχο.
- ΕΦΚΑ διπλής λειτουργίας: <3% μισθωτός (εδώ δεν υπολογίζονται εισφορές), ≥3% μη μισθωτός (`services/accounting-efka-operations.ts:153-197`).
- `double_entry` επιβάλλεται (`SetupPageContent.tsx:169`) — **μόνο ειδοποίηση, χωρίς καθολικό**.

## 4. Κενά

1. 🔴 Όπως η ΕΠΕ: δηλώνεται διπλογραφική αλλά τηρείται απλογραφικό βιβλίο (ACC-022 Α3).
2. Οικονομικές καταστάσεις, ΓΕΜΗ, υποστήριξη ορκωτού ελέγχου (εξαγωγές).
3. Μέλη ΔΣ <3% → χρειάζονται μισθοδοσία (ACC-022 Α7).
4. Μετοχολόγιο, πρακτικά.
5. Ομίλος εταιρειών (ενοποίηση) — μακροπρόθεσμο.

## 5. Πού ξεπερνάμε

- Η ΑΕ στον κλάδο είναι συνήθως **κατασκευαστική ή developer**: κόστος και περιθώριο **ανά κτίριο και ανά διαμέρισμα**, πωλήσεις ακινήτων (ADR-198), ΦΠΑ νεόδμητων, ποσοστό ολοκλήρωσης — όλα πάνω στα δεδομένα της πλατφόρμας (ACC-022 Β1, Β4, Β6).
- Ο ανταγωνισμός έχει μόνο γενικό module έργων.

## 6. Οδικός χάρτης

| Φάση | Περιεχόμενο |
|---|---|
| Φ1 | Μετάβαση στο διπλογραφικό καθολικό (ACC-022 Α3) |
| Φ2 | Οικονομικές καταστάσεις + ΓΕΜΗ + εξαγωγές για ορκωτό |
| Φ3 | Έντυπο Ν |
| Φ4 | Μετοχολόγιο + πρακτικά |
| Φ5 | Μισθοδοσία μελών ΔΣ (εξαρτάται από ACC-022 Α7) |
