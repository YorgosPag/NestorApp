# CHECK 3.8 — Missing i18n keys

**Missing i18n keys** (ADR-777 §8.41) — `t('key')` **και** `t('ns:key')` χωρίς αντιστοιχία στα locales. 🔴 **Μέχρι 2026-08-21 η πύλη και ο γεννήτορας της baseline της ήταν ΔΥΟ ΜΗΧΑΝΕΣ**, με **τρεις** αποκλίσεις: compat namespaces (μόνο η πύλη) · δικό του `extractTCalls` ο γεννήτορας · `keyExists` **plural-aware μόνο στην πύλη**. Μετρημένο στο ίδιο δέντρο την ίδια μέρα: **114 έναντι 6** ⇒ baseline φουσκωμένη ⇒ το ratchet συνέκρινε `τρέχον(Α)` με `baseline(Β)`, άρα αρχείο μπορούσε να **κερδίσει** παραβιάσεις και να **περάσει** (σχήμα ADR-749). Πλέον **ΜΙΑ** μηχανή: `scripts/lib/i18n-missing-keys-ratchet.js`. 🔴 **Ήταν ΔΟΜΙΚΑ ΤΥΦΛΗ στο `t('ns:key')`**: το SSoT έκανε `if (key.includes(':')) continue` με λόγο «these are explicitly scoped» — δηλαδή **ρητό ⇒ υποτίθεται σωστό**. Αλλά το ρητό namespace είναι **ισχυρισμός**, και ήταν λάθος **6/6** στο δείγμα· το `config.ts` **δεν ορίζει `fallbackNS`** ⇒ αστοχία = **ωμό κείμενο στην οθόνη**. **19 από τις 24 (79%) ήταν αόρατες.** ⚠️ Νέα ξεχωριστή `extractExplicitTCalls`, **ΠΟΤΕ σημαία** στην `extractTCalls`: εκείνη την καταναλώνει το shell slice, που χαρτογραφεί σε `{ns:null,key}` ⇒ θα ζητούσε κλειδί ονόματι `properties:x.y` μέσα στα **δικά του** namespaces. **Baseline v2 = ΔΥΟ ΚΑΔΟΙ** (`{bare, explicit}`): με έναν αριθμό η **ανταλλαγή** (−1 σκέτο, +1 ρητό) περνά αθόρυβα και το ρητό **ξαναγίνεται αόρατο** — αποδεδειγμένο ζωντανά (5→5, ρητά 0→1 ⇒ ΜΠΛΟΚ). Παλιό σχήμα δεκτό, αλλά ο αριθμός αφορά **μόνο τα σκέτα**: baseline μετρημένη πριν υπάρξει η έννοια «ρητό» **δεν έχει γνώμη**, και καμία γνώμη = **μηδέν**. 🔴 **ΔΕΝ ΕΙΧΕ ΠΟΤΕ Layer 2** — και ήταν γραμμένο στο workflow ως **αιτιολογία** («would be a no-op»)· ο πλήρης σαρωτής **ΗΤΑΝ ΗΔΗ ΕΚΕΙ**, απλώς **ΕΓΡΑΦΕ** τη baseline αντί να την **ΚΡΙΝΕΙ** ⇒ μπαγιάτικη **3 μήνες**. Πλέον `npm run i18n:keys-check` (2,4s) στο **υπάρχον** `i18n-governance.yml` με **`src/**`** στα triggers (χωρίς αυτό = `blocking-path-filtered` του 3.54)· μητρώο **33** πύλες **αμετάβλητο**. ⚠️ **ΜΗΝ διαβάσεις το 11→24 ως χειροτέρευση — είναι ΟΡΑΤΟΤΗΤΑ** (ίδιο σχήμα με 3.35). 🔶 **Δηλωμένο όριο**: μετρά **πλήθος** ανά κάδο, όχι **ταυτότητα** ⇒ ανταλλαγή **μέσα στον ίδιο κάδο** είναι αόρατη· το βρήκε η **πρώτη δοκιμή Layer 2 που βγήκε πράσινη** (είχε αντικαταστήσει αντί να προσθέσει). ⚠️ **ΜΗΝ ξαναγράψεις τοπικό `extractTCalls`/`keyExists`** — το `Β6` το μπλοκάρει. Tests: `npx jest scripts/__tests__/i18n-missing-keys-ratchet.test.js` (**18**: Κ1-Κ6 · Π1-Π6 με **πραγματικό** locale · Β1-Β6) + Ρ1-Ρ6 στο `i18n-namespace-extract.test.js`· **8/8 μεταλλάξεις**. ⚠️ **ΔΥΟ μεταλλάξεις βγήκαν ΠΡΑΣΙΝΕΣ**: η `Μ6` γιατί η άγκυρα έκρινε **κείμενο** («αναφέρει τη λέξη;») — θεραπεία ήταν **μία** μηχανή, όχι καλύτερο test· η `Μ8` γιατί η plural-επίγνωση **δεν είχε κλείδωμα** ενώ μόλις είχε κουνήσει τη baseline. Commands: `npm run i18n:keys-baseline` · `npm run i18n:keys-check`
