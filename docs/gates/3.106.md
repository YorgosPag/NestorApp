# CHECK 3.106 — Πύλη του ενός γραφέα του σχήματος καταλόγου

**«Γράφει κάποιος σχήμα καταλόγου έξω από τη μηχανή αποθήκευσης;»** (ADR-923 §5.9)

## 🔴 Η ΑΙΤΙΑ

Το σχήμα του καταλόγου (ADR-923 §5.2) έχει αναλλοίωτες που **δεν εκφράζονται σε κανόνα Firestore**:

1. κάθε οικογένεια επικυρώνεται **ολόκληρη** απέναντι στη βιβλιοθήκη ιδιοτήτων **μέσα στη συναλλαγή**·
2. ο `type` μιας ιδιότητας κλειδώνει όσο τη χρησιμοποιεί οικογένεια — η απάντηση έρχεται από το **παράγωγο**
   `attributeIds` της οικογένειας, που πρέπει να μένει συγχρονισμένο·
3. ο `ancestorIds` του δέντρου κατηγοριών ξαναγράφεται για **ολόκληρο** το υποδέντρο σε κάθε μετακίνηση·
4. κάθε εγγραφή κρατά **CAS** στο `revision` και γράφει **ίχνος** (ADR-195).

Οι κανόνες (`allow write: if false`) κλείνουν τον **πελάτη**. Ένα δεύτερο
`db.collection(COLLECTIONS.CATALOG_FAMILIES).doc(x).set(…)` στον διακομιστή θα τα παρέκαμπτε **όλα**, σιωπηλά.

## Κριτήρια

| | Ερώτημα | Θεραπεία |
|---|---|---|
| Κ1 | εγγραφή σε `COLLECTIONS.CATALOG_*` έξω από `src/server/catalog/catalog-store.server.ts` | γραφέας στο `src/server/catalog/` → `runCatalogTransaction` + `stage*` |
| Κ2 | `catalogDocRef(` έξω από μηχανή και αναγνώσεις βιβλιοθήκης | ίδια — η αναφορά της μηχανής είναι πόρτα γύρω από το Κ1 |
| Κ3 | εξαίρεση χωρίς λόγο | `// catalog-schema-authority-exempt: <λόγος>` στη γραμμή πάνω |
| Κ4 | η μηχανή δεν κάνει `runTransaction(`/`recordTrackedEntityWrite(`, ή γραφέας δεν περνά από `runCatalogTransaction(` | καλωδίωσε ξανά |
| Κ5 | `catalog_*` στο `WRITE_ALLOWED_COLLECTIONS` του MCP | αφαίρεσέ το — η απευθείας εγγραφή παρακάμπτει τη μηχανή |

## Άγκυρες

`npm run test:catalog-schema-authority` — κάθε κριτήριο σε «πυροδοτεί» **και** «σιωπά», παρονομαστής στο πραγματικό
δέντρο («ο σαρωτής είδε τη μηχανή»), και **μετάλλαξη**: γραφέας που παρακάμπτει τη συναλλαγή σε αντίγραφο της ρίζας ⇒ κόκκινο.

## ⚠️ ΜΗΝ

- **ΜΗΝ** προσθέσεις αρχείο στο `DOC_REF_USERS` «επειδή βολεύει»: κάθε τέτοιο αρχείο είναι πόρτα γύρω από την επικύρωση.
- **ΜΗΝ** το κάνεις ratchet: μία εγγραφή έξω από τη μηχανή αρκεί για οικογένεια που δείχνει σε ανύπαρκτη ιδιότητα.

## Δηλωμένα όρια

- Βλέπει εγγραφές με **ρητό** `COLLECTIONS.CATALOG_*` (ή μεταβλητή που το κρατά) και κλήσεις `catalogDocRef(`.
  Εγγραφή μέσω συλλογής που δίνεται ως **συμβολοσειρά** (`'catalog_families'`) δεν τη βλέπει — το ίδιο όριο με τις
  αδελφές 3.102 · 3.87 · 3.88.
