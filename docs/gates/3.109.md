# CHECK 3.109 — Πύλη του απομονωμένου χώρου εργασίας

**«Κάνει πράκτορας commit κατευθείαν στο `main`, αντί στο δικό του κλαδί;»** (ADR-925)

## 🔴 Η ΑΙΤΙΑ

Όταν όλοι οι πράκτορες γράφουν στο ίδιο δέντρο, κανένα εργαλείο δεν ξέρει ποια αλλαγή ανήκει σε ποιον.
Το μετρημένο κόστος είναι ξένη δουλειά μέσα σε commits και μεταλλαγμένος κώδικας στο `main`. Η θεραπεία
είναι δομική: κάθε εργασία σε δικό της worktree και κλαδί.

## Κανόνες

| Ερώτηση | Απόφαση |
|---|---|
| Πράκτορας (`CLAUDECODE=1`) στο `main`, `enforce: true` | ⛔ μπλοκάρει |
| Πράκτορας σε δικό του κλαδί | ✅ περνά |
| Άνθρωπος στο `main` | ✅ περνά: ο Giorgio κρατά τον δρόμο για επείγουσα διόρθωση |
| `enforce: false` | ✅ περνά |

## ⚠️ ΜΗΝ

- **ΜΗΝ γυρίσεις το `enforce` σε `true` όσο το κύριο αντίγραφο έχει αδέσμευτη δουλειά πρακτόρων**: θα
  σταματήσεις κάθε τους commit. Η αλλαγή είναι απόφαση του Giorgio.
