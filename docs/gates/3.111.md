# CHECK 3.111 — Πύλη των πράξεων έργου

**Το ερώτημα:** μπορεί ο ρόλος έργου να δώσει πράξη που κανείς δεν δήλωσε, ή να μείνει νεκρή πράξη που δηλώθηκε;

**Το γεγονός (2026-11-02):** ο `project_manager` είχε γραμμές στον κατάλογο ρόλων που δεν έκαναν τίποτα, γιατί οι διαδρομές δεν έδιναν έργο στον κριτή. Και το `DELETE /api/trash/.../permanent-delete` ζητούσε μόνο σύνδεση.

**Κριτήρια:**

| | Έλεγχος |
|---|---|
| Κ1 | Κάθε πράξη του `PROJECT_SCOPED_ACTIONS` έχει γραμμή στον `PROJECT_ROLE_POLICY`, και κάθε γραμμή πράξη |
| Κ2 | Κάθε πράξη έχει σημείο επιβολής: διαδρομή με `permissions` μαζί με `permissionResource`, ή δηλωμένο αρχείο με `projectId` |
| Κ3 | Κανένα `permissionOptions` σε διαδρομή: το έργο έρχεται από τον πόρο, ποτέ από το αίτημα (AIP-203) |
| Κ4 | Κανένα αντίγραφο του καταλόγου (πίνακας με ≥3 πράξεις έξω από τα δεδομένα ρόλων) |
| Κ5 | `trash:entities:purge` και `projects:floors:delete` έξω από τον κατάλογο, και οι δύο διαδρομές `permanent-delete` ζητούν το δικαίωμα |

⚠️ **ΜΗΝ** βάλεις μη αναστρέψιμη πράξη στον κατάλογο. Ο όροφος δεν έχει κάδο, άρα η διαγραφή του μένει εκτός.

⚠️ Η πύλη κρίνει τη δήλωση. Τη συμπεριφορά την κρίνει το Τ3 του `building-floor-role-matrix.route.test.ts`.

Tests: `npm run test:project-scoped-actions`. Αναφορά: `npm run project-scoped-actions:report`.
